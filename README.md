## Reinforcement Learning Homework

성신여자대학교 강화학습(2026-2) 과제 및 연구 기록
교재: Sutton & Barto, *Reinforcement Learning: An Introduction* (2nd ed., 2018) — Part I (Chapter 2–8, Tabular Solution Methods)

## 실행 환경
- Python 3.11, numpy, matplotlib, scipy, jupyter (`requirements.txt`)
- Windows 11 + VSCode Jupyter

## 코드 작성 방식
- 강의 제공 노트북(rl-week)의 코드 구조(`step`, `epsilon_greedy`, `train_*`)를 따른다
- 교재 의사코드와 1:1로 대응되도록 작성
- 결과는 여러 시드(run)로 평균해 보고하고, 가정한 설정은 노트북에 명시
